INTRODUCTION 
Electric vehicle (EV) charging station availability in urban infrastructure depends on many factors, 
including the number of total ports, active plugins, connector types, queue length, average dwell 
time, tariff rates, and ambient weather conditions. Reviewing these factors manually is difficult 
when thousands of operational observations are involved. Data analysis and machine learning 
provide methods for organizing charging infrastructure information, identifying usage patterns, and 
estimating the station availability status from input features. 
This project develops a basic real-time EV charging station availability and demand prediction 
system using MongoDB and Python. MongoDB stores the charging station operational records in a 
document-oriented format. Python libraries are used to retrieve, preprocess, analyze, visualize, and 
model the data. 
The system uses two classification algorithms: 
 Random Forest Classifier: combines the votes of many decision trees to predict a category. 
 Logistic Regression: estimates the probability of each category using a linear combination 
of the input features. 
Both models are evaluated on a held-out test set so their accuracy, precision, recall, and F1 -scores 
can be compared. The project demonstrates the integration of database management, data analysis, 
visualization, and supervised machine learning in a single Python application. 
 
 
PROBLEM STATEMENT 
EV charging data is usually recorded as many separate observations across cities, station IDs, and 
timestamps. Examining individual records does not show which operational factors are associated 
with station congestion or queue build-up. A structured database and an automated analysis process 
make it easier to retrieve records, summarize charging conditions, and apply prediction algorithms. 
The problem addressed by this project is to implement a Python-based system that stores EV 
charging station records in MongoDB, performs data analysis and visualization, and compares two 
classification models for predicting the station status level (Available, Busy, or Fully 
Congested) of a charging record.

CONCLUSION 
 
The Real-Time EV Charging Station Availability & Demand Predictor project successfully 
addresses one of the most critical hurdles facing the modern electric vehicle ecosystem: range 
anxiety and inefficient charging infrastructure utilization. As EV adoption rapidly accelerates 
worldwide, drivers require reliable, instant visibility into charging station availability, while grid 
operators need accurate demand forecasts to prevent localized power overload. This project bridges 
raw sensor and operational data with actionable, real-time intelligence by engineering a resilient, 
scalable, end-to-end data processing and machine learning framework. 
 
The architecture was intentionally designed to blend flexible data storage, high-performance batch 
and distributed data transformations, and robust predictive modeling. At the foundation, MongoDB 
serves as an agile document repository, seamlessly storing raw telemetry logs, station status metrics, 
and timestamped usage records. The data pipeline utilizes Pandas for preliminary cleaning and 
exploratory analysis, transitioning into PySpark to provide scalable feature engineering 
capabilities—such as One-Hot Encoding for categorical station attributes and StandardScaler 
normalization for numerical power and time features. This ensures that the data pipeline remains 
efficient even as data volume scales across extensive charging networks. 
 
For core predictive modeling, high-performance classification algorithms were implemented, 
including a Random Forest ensemble with 300 estimators alongside Logistic Regression. The 
models were subjected to rigorous evaluation metrics beyond simple accuracy, focusing heavily on 
Precision, Recall, Macro F1-score, and Confusion Matrices. Minimizing false-positive 
predictions—in which a driver is incorrectly directed to an occupied or offline charger—was 
prioritized to maintain high operational reliability. The resulting ensemble model demonstrates 
exceptional performance in classifying station demand levels and predicting real-time availability. 
Furthermore, the live inference pipeline demonstrates the practical application of this system by 
processing incoming status updates on-the-fly and outputting immediate availability scoring. 
 
In conclusion, the Real-Time EV Charging Station Availability & Demand Predictor proves that 
combining modern data engineering tools with machine learning effectively solves real-world 
logistics challenges. By transforming fragmented charging data into highly accurate availability 
predictions, the project enhances user confidence in EV ownership, maximizes charging station 
profitability, and contributes significantly to the sustainable management of smart urban energy 
grids.
